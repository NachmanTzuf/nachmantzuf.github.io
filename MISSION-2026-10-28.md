- Existing lever training already has five rounds and root-based major audio, but no modal curriculum; guided semitone audio uses incorrect root-relative indexing.
- Existing Git configuration contains a credential in its remote. Never reproduce it or include it in archives; owner should revoke/rotate it. Git currently errors about work tree; investigate without resetting changes.
- No evidence yet supports recognition under 300ms, empirical efficacy guarantees, instant mastery, or 220+ current usable levels. Omit unsupported claims from new deliverables.
