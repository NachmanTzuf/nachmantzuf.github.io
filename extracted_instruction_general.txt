EXECUTIVE SYSTEM ARCHITECTURE
This specification defines the complete ear training curriculum for the production mobile application. Based on a rigorous
audit of all screenshots across single note trainig, note sequance training, and other instractions and deta,
this document maps out every single level, parameter, and rule. The two major paths have been mathematically balanced to
exactly 68 levels each by pruning unplayable extreme speeds and integrating a rich, pedagogical 27-level Advanced
Harmonic Dyads track.
1. System Fundamentals & Metric Decoding
Every level card contains five distinct engine parameters that determine game behavior:
Rounds per Session: Displayed as 10: or 20: (50 in mastery finals). This is the exact number of trials before calculating user
score.
Register / Octave Scope: 1 octave limits tone playback to the middle vocal register (C4 to C5). many octaves spreads
tones across low, middle, and high registers.
Harmonic Cadence: Played prior to each question (I-IV-V-I in major; i-iv-V-i in minor) to establish the tonic center.
Diatonic Note Matrix: 8 inline blocks representing the diatonic scale degrees (1=Do, 2=Re, 3=Mi, 4=Fa, 5=Sol, 6=La, 7=Ti,
8=Do). Dark blocks indicate active notes user must recognize. In chromatic modes, a 12-block piano matrix is utilized.
Key Signature Modes: C major/minor (fixed tonic C), Not-C (session locked to a single random non-C key), and Random
(every question switches to a new random key).
Tonic Resolution Pipeline: Upon correct answer submission, the engine plays the stepwise resolution back to the nearest
tonic (1 ← 2 ← 3 ← 4 and 5 → 6 → 7 → 1).
