# WHAT TO AVOID & REJECTED ANTI-PATTERN ARCHIVE

## 1. PURPOSE
When an agent completes a milestone or deliverable, and the user reviews it and expresses dissatisfaction, critiques it, or orders changes:
1. The rejected artifact is automatically preserved in this folder with a timestamp suffix before changes are applied.
2. The critique and failure mode are logged below so future agents never repeat this mistake.
